# Nyxcode

A modern code editor with live collaboration.

## Features

- **Code Editing**: Modern syntax highlighting for multiple languages
- **File Management**: Open, create, and organize files and folders
- **Live Collaboration**: Share code sessions with other developers (coming soon)
- **Terminal**: Built-in terminal for running commands
- **Preview**: Split-screen HTML and code preview

## Getting Started

1. **Install**: Run the installer and follow the setup wizard
2. **Open**: Launch Nyxcode from your Start Menu or Desktop shortcut
3. **Create/Open**: Start by opening a folder or file to begin editing

## Usage

- **Ctrl+O**: Open file
- **Ctrl+Shift+O**: Open folder
- **Ctrl+N**: New untitled file
- **Ctrl+S**: Auto-save
- **Ctrl+P**: Command palette
- **Ctrl+B**: Toggle sidebar
- **Ctrl+`**: Toggle terminal

## Sign In

Sign in with your email or OAuth (Google, GitHub, Yahoo) to:
- Access cloud file storage
- Enable live collaboration
